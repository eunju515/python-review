    Chapter 07. 우리 반 시험 성적 분석하기 – 여러 함수를 한 번에 활용¶

    Part 3: 실전 체험 – 데이터분석, 이런 거구나! ⏱️ 예상 학습 시간: 50분 | 📍 전체 9차시 중 7차시

    🎯 이 장에서 배우는 것¶

    • 여러 통계 함수(합계·평균·최고점·최저점·범위)를 조합하여 하나의 데이터셋을 다각도로 분석할 수 있다.
    • 분석 결과를 print문으로 보기 좋게 정리하여 성적 리포트 형태로 출력할 수 있다.
    • 숫자 결과를 보고 "이 데이터가 말해주는 것"을 한 문장으로 해석할 수 있다.

    📚 핵심 개념¶

    개념 1: 함수 조합 – 도구 상자에서 필요한 도구를 꺼내 쓰듯이¶

    함수 조합은 마치 요리할 때 여러 조리 도구를 차례로 꺼내 쓰는 것과 같아요. 칼로 썰고, 냄비에 끓이고, 체로 거르듯이 — 데이터도 함수마다 다른 방식으로 가공합니다.

    정확한 정의: 함수 조합이란 하나의 데이터(리스트)에 여러 함수를 순서대로 적용하여 다양한 관점의 결과를 얻는 것입니다.

    예시로 확인: 

    scores = [85, 92, 78, 65, 90]

print(sum(scores))          # 합계: 410
print(sum(scores) / len(scores))  # 평균: 82.0
print(max(scores))          # 최고점: 92
print(min(scores))          # 최저점: 65
print(max(scores) - min(scores))  # 범위: 27

    같은 리스트 scores에 함수만 바꿔 적용했을 뿐인데, 다섯 가지 정보를 얻었습니다! 🎉

    개념 2: 범위(Range) – 점수가 얼마나 퍼져 있는지 보여주는 숫자¶

    점수 범위는 마치 키 차이와 같아요. 반에서 가장 키 큰 친구와 가장 작은 친구의 차이가 클수록, 키가 '고르지 않다'는 뜻이죠. 점수도 마찬가지입니다.

    정확한 정의: 범위 = 최고점 - 최저점. 이 값이 클수록 점수 편차가 크고(고르지 않음), 작을수록 점수가 비슷한 수준으로 모여 있습니다.

    graph LR A[최저점 min] -->|범위가 크다| B[최고점 max] C[최저점 min] -->|범위가 작다| D[최고점 max] style A fill:#ff9999 style B fill:#99ccff style C fill:#ff9999 style D fill:#99ccff

    해석 예시: - 국어 범위 = 45점 → "실력 차이가 매우 크다, 어려웠던 과목일 수 있다" - 영어 범위 = 20점 → "대부분 비슷한 수준이다, 비교적 쉬웠거나 고른 과목"

    🔨 따라하기¶

    Step 1: 데이터 준비하기¶

    가상의 20명 학생 성적 데이터를 리스트로 만들겠습니다.

    코드: 

    # 우리 반 20명의 과목별 점수
korean  = [85, 92, 78, 65, 90, 55, 88, 73, 61, 95,
           70, 83, 77, 68, 91, 59, 87, 74, 80, 66]

english = [90, 88, 82, 75, 93, 70, 85, 79, 72, 96,
           78, 84, 80, 71, 89, 68, 91, 76, 83, 74]

math    = [72, 85, 60, 55, 88, 45, 79, 63, 50, 91,
           58, 76, 65, 52, 83, 41, 80, 67, 71, 59]

    (오류 없이 실행되면 성공 — 아직 출력은 없습니다)

    Step 2: 한 과목 분석 함수 만들기¶

    매번 같은 코드를 반복하는 건 비효율적입니다. 함수로 묶어 어떤 과목에든 재사용하세요!

    코드: 

    def analyze(subject_name, scores):
    total   = sum(scores)
    average = total / len(scores)
    highest = max(scores)
    lowest  = min(scores)
    spread  = highest - lowest       # 범위
    return subject_name, total, average, highest, lowest, spread

    실행 결과: 

    (함수 정의만 한 상태 — 아직 호출 전)

    Step 3: 리포트 출력 함수 만들기¶

    분석 결과를 보기 좋게 찍어주는 함수를 따로 만들면, 코드가 훨씬 읽기 쉬워집니다.

    코드: 

    def print_report(subject_name, total, average, highest, lowest, spread):
    print(f"========== {subject_name} 성적 리포트 ==========")
    print(f"  합계  : {total}점")
    print(f"  평균  : {average:.1f}점")   # 소수점 1자리
    print(f"  최고점: {highest}점")
    print(f"  최저점: {lowest}점")
    print(f"  범위  : {spread}점")
    print()

    💡 :.1f 는 소수점 아래 1자리까지만 보여주는 포맷입니다. 82.0, 79.5 처럼 깔끔하게 출력됩니다.

    Step 4: 세 과목 한꺼번에 분석하기¶

    이제 함수 두 개를 조합해 세 과목을 한 번에 분석합니다.

    코드: 

    # 각 과목 분석 후 바로 출력
print_report(*analyze("국어", korean))
print_report(*analyze("영어", english))
print_report(*analyze("수학", math))

    💡 * 는 함수가 반환한 여러 값을 풀어서 다음 함수에 넣어주는 표현입니다. analyze()가 6개 값을 돌려주면, *가 그것을 print_report()의 6개 인자로 펼쳐줍니다.

  평균  : 76.9점

  최저점: 55점
  범위  : 40점

========== 영어 성적 리포트 ==========

  평균  : 81.2점
  최고점: 96점
  최저점: 68점
  범위  : 28점

    Step 5: 결과 해석하기¶

    숫자만 보면 끝이 아닙니다. "이 숫자가 무엇을 의미하는가?" 를 코드로 판단해봅시다.

    코드: 

    subjects = ["국어", "영어", "수학"]
averages = [
    sum(korean)  / len(korean),
    sum(english) / len(english),
    sum(math)    / len(math)
]
spreads = [
    max(korean)  - min(korean),
    max(english) - min(english),
    max(math)    - min(math)
]

# 가장 어려웠던 과목 (평균이 가장 낮은 과목)
hardest_idx = averages.index(min(averages))
print(f"가장 어려웠던 과목: {subjects[hardest_idx]} (평균 {min(averages):.1f}점)")

# 점수 편차가 가장 큰 과목 (범위가 가장 큰 과목)
widest_idx = spreads.index(max(spreads))
print(f"점수 편차 가장 큰 과목: {subjects[widest_idx]} (범위 {max(spreads)}점)")

    실행 결과: 

    가장 어려웠던 과목: 수학 (평균 67.0점)
점수 편차 가장 큰 과목: 수학 (범위 50점)

    🔍 해석: 수학은 평균도 가장 낮고 범위도 가장 넓습니다. 즉, 전반적으로 어려웠고 학생들 사이의 실력 차이도 가장 컸던 과목이라고 해석할 수 있습니다.

    📝 전체 코드¶

    # ==============================
# 우리 반 시험 성적 분석 리포트
# ==============================

# 1. 데이터
korean  = [85, 92, 78, 65, 90, 55, 88, 73, 61, 95,
           70, 83, 77, 68, 91, 59, 87, 74, 80, 66]
english = [90, 88, 82, 75, 93, 70, 85, 79, 72, 96,
           78, 84, 80, 71, 89, 68, 91, 76, 83, 74]
math    = [72, 85, 60, 55, 88, 45, 79, 63, 50, 91,
           58, 76, 65, 52, 83, 41, 80, 67, 71, 59]

# 2. 분석 함수
def analyze(subject_name, scores):
    total   = sum(scores)
    average = total / len(scores)
    highest = max(scores)
    lowest  = min(scores)
    spread  = highest - lowest
    return subject_name, total, average, highest, lowest, spread

# 3. 출력 함수
def print_report(subject_name, total, average, highest, lowest, spread):
    print(f"========== {subject_name} 성적 리포트 ==========")
    print(f"  합계  : {total}점")
    print(f"  평균  : {average:.1f}점")
    print(f"  최고점: {highest}점")
    print(f"  최저점: {lowest}점")
    print(f"  범위  : {spread}점")
    print()

# 4. 세 과목 리포트 출력
print_report(*analyze("국어", korean))
print_report(*analyze("영어", english))
print_report(*analyze("수학", math))

# 5. 종합 해석
subjects = ["국어", "영어", "수학"]
averages = [sum(korean)/len(korean), sum(english)/len(english), sum(math)/len(math)]
spreads  = [max(korean)-min(korean), max(english)-min(english), max(math)-min(math)]

hardest_idx = averages.index(min(averages))
widest_idx  = spreads.index(max(spreads))

print(f"가장 어려웠던 과목: {subjects[hardest_idx]} (평균 {min(averages):.1f}점)")
print(f"점수 편차 가장 큰 과목: {subjects[widest_idx]} (범위 {max(spreads)}점)")

    ⚠️ 주의할 점¶

    1. 평균 계산 시 len() 빠뜨리지 않기

    sum(scores) / 20 처럼 숫자를 직접 쓰면, 나중에 데이터 개수가 바뀌었을 때 수정해야 할 곳이 생깁니다. 항상 len(scores)를 사용하는 습관을 들이세요.

    # ❌ 고정 숫자 사용 — 나쁜 습관
average = sum(scores) / 20

# ✅ len() 사용 — 좋은 습관
average = sum(scores) / len(scores)

    2. * 언패킹은 반환값 개수가 맞아야 한다

    analyze()가 6개 값을 반환하고 print_report()가 6개 인자를 받아야 * 언패킹이 정상 작동합니다. 두 함수의 값 개수가 다르면 오류가 납니다.

    ✅ 점검하기¶

    1. max(scores) - min(scores)로 구한 값은 무엇을 의미하나요?

    정답 확인 **범위(Range)** 입니다. 가장 높은 점수와 가장 낮은 점수의 차이로, 점수가 얼마나 퍼져 있는지(편차)를 나타냅니다. 값이 클수록 학생들 간 실력 차이가 크다는 의미입니다.

    2. 아래 코드에서 *의 역할은 무엇인가요?

    print_report(*analyze("수학", math))
    정답 확인 `analyze()`가 반환하는 **튜플(여러 값 묶음)을 풀어서(언패킹)** `print_report()`의 각 인자로 하나씩 전달해주는 역할입니다. `*` 없이 쓰면 튜플 하나가 첫 번째 인자로만 들어가 오류가 납니다.

    3. 세 과목 중 평균이 가장 높은 과목을 코드 결과로 확인했을 때, 그 과목이 "가장 쉬웠다"고 단정할 수 있을까요?

    정답 확인 **단정할 수 없습니다.** 평균이 높다는 것은 하나의 단서일 뿐입니다. 범위(편차), 학생 수, 시험 난이도 설계 등 다른 요소도 함께 봐야 정확한 해석이 가능합니다. 데이터 분석에서 **하나의 수치만으로 결론 내리지 않는 것**이 중요합니다.
