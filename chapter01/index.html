    Chapter 01. 다시 만난 파이썬 – 변수와 자료형 복습¶

    Part 1. 감 되찾기 – 파이썬, 다시 만나자!

    🎯 이 장에서 배우는 것¶

    • 변수에 값을 저장하고 출력하는 기본 문법을 다시 떠올릴 수 있다.
    • 정수, 실수, 문자열, 불(bool) 자료형을 구분하고 type()으로 확인할 수 있다.
    • 사칙연산과 문자열 결합을 파이썬으로 수행할 수 있다.

    📚 핵심 개념¶

    개념 1. 변수 – 이름표가 붙은 상자¶

    비유로 시작: 변수는 마치 학교 사물함과 같아요.
    사물함에 이름표를 붙이고, 그 안에 물건을 넣어두는 것처럼 — 파이썬에서는 변수 이름을 붙이고, 그 안에 값을 저장합니다.

    정확한 정의:
    변수(variable)란 데이터를 저장하는 공간에 붙인 이름입니다. = 기호를 사용해 값을 저장(대입)합니다.

    예시로 확인:

    name = "지수"       # 문자열 저장
score = 95          # 정수 저장
print(name)         # 출력: 지수
print(score)        # 출력: 95

    💡 =는 수학의 '같다'가 아니라 오른쪽 값을 왼쪽에 저장한다는 의미예요!

    개념 2. 자료형 – 데이터의 종류¶

    비유로 시작: 자료형은 마치 음식 용기의 종류와 같아요.
    국은 그릇에, 밥은 공기에, 반찬은 접시에 담듯 — 데이터도 그 성격에 맞는 자료형에 담깁니다.

    정확한 정의:
    자료형(data type)이란 변수에 저장되는 데이터의 종류를 말합니다. 파이썬은 자동으로 자료형을 판단해줍니다.

    주요 자료형 4가지:

    • int (정수) – 소수점 없는 숫자. 예: 100, -5, 0
    • float (실수) – 소수점 있는 숫자. 예: 3.14, 36.5
    • str (문자열) – 따옴표로 감싼 텍스트. 예: "안녕", '파이썬'
    • bool (불) – 참/거짓 두 가지. 예: True, False
    graph TD A[데이터] --> B[숫자형] A --> C[문자형] A --> D[논리형] B --> E[int 정수\n예: 95] B --> F[float 실수\n예: 36.5] C --> G[str 문자열\n예: '지수'] D --> H[bool 불\n예: True]

    type() 함수로 자료형 확인:

    print(type(95))       # <class 'int'>
print(type(36.5))     # <class 'float'>
print(type("지수"))   # <class 'str'>
print(type(True))     # <class 'bool'>

    🔨 따라하기¶

    내 프로필 정보를 변수로 저장하고 출력하는 코드를 단계별로 작성해봐요!

    Step 1. 프로필 변수 만들기¶

    코드: 

    # 내 프로필 정보를 변수에 저장
my_name = "김파이"        # 이름 (문자열)
my_age = 17               # 나이 (정수)
my_height = 168.5         # 키 (실수)
is_student = True         # 학생 여부 (불)

    실행 결과: 

    (아직 출력 없음 – 저장만 했어요!)

    Step 2. 변수 출력하기¶

    코드: 

    print(my_name)
print(my_age)
print(my_height)
print(is_student)

    실행 결과: 

    김파이
17
168.5
True

    Step 3. 자료형 확인하기¶

    코드: 

    print(type(my_name))
print(type(my_age))
print(type(my_height))

    실행 결과: 

    <class 'str'>
<class 'int'>
<class 'float'>

    Step 4. 문자열 결합과 사칙연산¶

    코드: 

    # 문자열 결합: + 로 이어붙이기
greeting = "안녕하세요, " + my_name + "님!"
print(greeting)

# 사칙연산
next_age = my_age + 1
print("내년 나이:", next_age)

    실행 결과: 

    안녕하세요, 김파이님!
내년 나이: 18

    Step 5. 한 줄로 예쁘게 출력하기¶

    print() 안에 여러 값을 ,로 나열하면 공백을 두고 출력해줘요.

    코드: 

    print("이름:", my_name, "/ 나이:", my_age, "/ 키:", my_height)

    실행 결과: 

    이름: 김파이 / 나이: 17 / 키: 168.5

    📝 전체 코드¶

    # ===== Chapter 01. 내 프로필 변수로 저장하기 =====

# 1. 프로필 변수 저장
my_name = "김파이"
my_age = 17
my_height = 168.5
is_student = True

# 2. 자료형 확인
print(type(my_name))      # <class 'str'>
print(type(my_age))       # <class 'int'>
print(type(my_height))    # <class 'float'>

# 3. 문자열 결합
greeting = "안녕하세요, " + my_name + "님!"
print(greeting)

# 4. 사칙연산
next_age = my_age + 1
print("내년 나이:", next_age)

# 5. 프로필 한 줄 출력
print("이름:", my_name, "/ 나이:", my_age, "/ 키:", my_height)

    ⚠️ 주의할 점¶

    ① 숫자와 문자열은 +로 바로 이을 수 없어요

    # ❌ 오류 발생!
print("나이: " + 17)

# ✅ str()로 변환 후 결합
print("나이: " + str(17))

    숫자를 문자열로 바꾸려면 str(), 문자열을 정수로 바꾸려면 int()를 사용하세요.

    ② 변수 이름 규칙을 지켜요

    • 숫자로 시작하면 안 돼요: 1name ❌ → name1 ✅
    • 공백 대신 언더바(_)를 쓰세요: my name ❌ → my_name ✅

    ✅ 점검하기¶

    Q1. 아래 코드에서 x의 자료형은 무엇일까요? 

    x = "3.14"

    정답 확인 **str (문자열)** 입니다. 따옴표로 감싸여 있기 때문에 숫자처럼 보여도 문자열이에요. `type(x)`를 실행하면 ``이 출력됩니다.

    Q2. 다음 중 실행하면 오류가 나는 코드는 어느 것일까요?

    • (A) print("점수: " + str(100))
    • (B) print("점수: " + 100)
    • (C) print("점수:", 100)
    정답 확인 **(B)** 가 오류입니다. 문자열과 정수를 `+`로 직접 연결할 수 없어요. (A)처럼 `str()`로 변환하거나, (C)처럼 `,`를 사용해야 합니다.

    Q3. True와 False는 어떤 자료형인가요?

    정답 확인 **bool (불)** 형입니다. 참(`True`)과 거짓(`False`) 두 가지 값만 가질 수 있으며, 조건 판단에 자주 사용됩니다. 반드시 첫 글자를 **대문자**로 써야 해요!
