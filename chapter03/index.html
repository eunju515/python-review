    갈림길을 만들자 – 조건문과 반복문 복습¶

    Part 1 | 감 되찾기 – 파이썬, 다시 만나자! | 3차시 / 9차시

    🎯 이 장에서 배우는 것¶

    • if-elif-else 조건문을 사용하여 데이터에 따라 다른 결과를 출력할 수 있다
    • for 반복문을 사용하여 리스트의 모든 요소를 하나씩 처리할 수 있다
    • 조건문과 반복문을 조합하여 리스트에서 특정 조건을 만족하는 값을 골라낼 수 있다

    📚 핵심 개념¶

    개념 1: 조건문 (if-elif-else)¶

    비유로 시작: 조건문은 마치 지하철 교통카드 단말기와 같아요. 잔액이 충분하면 🟢 통과, 부족하면 🔴 삑! 하고 막는 것처럼, 조건에 따라 서로 다른 동작을 합니다.

    정확한 정의: if는 "만약 ~라면"이라는 뜻입니다. 조건이 참(True)이면 해당 블록을 실행하고, 거짓(False)이면 다음 조건으로 넘어갑니다. elif는 "아니면 혹시 ~라면", else는 "그 외 모두"를 담당합니다.

    구조 한눈에 보기:

    flowchart TD A[점수 입력] --> B{90점 이상?} B -- 예 --> C[등급: A] B -- 아니오 --> D{80점 이상?} D -- 예 --> E[등급: B] D -- 아니오 --> F[등급: C 이하]

    예시로 확인:

    score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C 이하"

print(grade)  # B

    💡 들여쓰기 주의! 파이썬은 들여쓰기(스페이스 4칸)로 블록을 구분합니다. 콜론(:) 다음 줄은 반드시 들여써야 해요.

    개념 2: 반복문 (for)¶

    비유로 시작: for 반복문은 마치 출석부를 부르는 선생님과 같아요. 명단에 있는 학생을 처음부터 끝까지 한 명씩 차례로 호명하듯, 리스트의 요소를 하나씩 꺼내서 처리합니다.

    정확한 정의: for 변수 in 리스트: 형태로 쓰며, 리스트의 각 요소가 변수에 하나씩 담기면서 블록이 반복 실행됩니다.

    구조 한눈에 보기:

    flowchart LR A["scores = [92, 75, 88]"] --> B["첫 번째: score = 92"] B --> C["두 번째: score = 75"] C --> D["세 번째: score = 88"] D --> E[반복 종료]

    예시로 확인:

    scores = [92, 75, 88]

for score in scores:
    print(score)

    92
75
88

    🔨 따라하기¶

    이제 두 개념을 합쳐서 "점수 리스트를 돌며 각 학생의 등급을 출력하는 프로그램" 을 단계별로 만들어봅시다.

    Step 1: 점수 리스트 준비하기¶

    코드:

    # 학생 5명의 점수 리스트
scores = [92, 75, 88, 61, 95]

    아직 실행해도 아무것도 출력되지 않아요. 데이터만 준비한 단계입니다.

    Step 2: for문으로 점수 하나씩 꺼내기¶

    코드:

    scores = [92, 75, 88, 61, 95]

for score in scores:
    print(score)  # 점수를 하나씩 출력

    실행 결과:

    92
75
88
61
95

    score라는 변수에 리스트 값이 하나씩 들어오는 게 보이시나요?

    Step 3: 조건문으로 등급 판단하기¶

    이번엔 각 점수에 맞는 등급을 판단하는 if-elif-else를 추가합니다.

    코드:

    scores = [92, 75, 88, 61, 95]

for score in scores:
    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    else:
        grade = "D"

    print(f"점수: {score} → 등급: {grade}")

    실행 결과:

    점수: 92 → 등급: A
점수: 75 → 등급: C
점수: 88 → 등급: B
점수: 61 → 등급: D
점수: 95 → 등급: A

    f"..." 안에서 중괄호 {변수명}를 쓰면 변수 값이 바로 출력됩니다. 이걸 f-string이라고 해요!

    Step 4: 특정 조건의 학생만 골라내기¶

    90점 이상인 학생만 따로 출력해볼까요? if를 필터처럼 활용합니다.

    코드:

    scores = [92, 75, 88, 61, 95]

print("=== 우수 학생 명단 (90점 이상) ===")
for score in scores:
    if score >= 90:           # 90점 이상인 경우만
        print(f"점수: {score}")

    실행 결과:

    === 우수 학생 명단 (90점 이상) ===
점수: 92
점수: 95

    조건에 맞지 않는 점수(75, 88, 61)는 그냥 지나칩니다. else 없이 if만 써도 돼요!

    📝 전체 코드¶

    # 학생 점수 등급 판별 프로그램

scores = [92, 75, 88, 61, 95]

# 모든 학생 등급 출력
print("=== 전체 학생 등급 ===")
for score in scores:
    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    else:
        grade = "D"
    print(f"점수: {score} → 등급: {grade}")

# 90점 이상 우수 학생만 출력
print("\n=== 우수 학생 명단 (90점 이상) ===")
for score in scores:
    if score >= 90:
        print(f"점수: {score}")

    실행 결과:

    === 전체 학생 등급 ===
점수: 92 → 등급: A
점수: 75 → 등급: C
점수: 88 → 등급: B
점수: 61 → 등급: D
점수: 95 → 등급: A

=== 우수 학생 명단 (90점 이상) ===
점수: 92
점수: 95

    ⚠️ 주의할 점¶

    1. elif 순서가 중요합니다! 조건은 위에서부터 순서대로 검사합니다. 만약 elif score >= 70을 맨 위에 쓰면, 92점도 "C"가 되어버립니다. 넓은 조건은 아래, 좁은(큰) 조건은 위에 써야 해요.

    2. 들여쓰기는 칸 수를 일정하게! if 블록 안에 for가 있고, 그 안에 또 if가 있으면 들여쓰기가 겹칩니다. 스페이스 4칸씩 일관되게 유지하세요. 탭(Tab)과 스페이스를 섞으면 오류가 납니다.

    ✅ 점검하기¶

    Q1. 아래 코드의 실행 결과는 무엇일까요?

    temps = [28, 22, 35, 19]
for t in temps:
    if t >= 25:
        print(f"{t}도: 더운 날")
    정답 확인 
    28도: 더운 날
35도: 더운 날
    25도 미만인 22와 19는 조건을 만족하지 않아 출력되지 않습니다.

    Q2. elif와 else의 차이는 무엇인가요?

    정답 확인 `elif`는 **추가 조건을 검사**합니다 ("아니면 혹시 ~라면?"). `else`는 **앞의 모든 조건이 거짓일 때** 실행되는 "나머지 전부"를 담당합니다. `else`에는 조건식을 쓰지 않아요.

    Q3. 아래 리스트에서 짝수만 출력하려면 if 조건을 어떻게 써야 할까요?

    numbers = [1, 2, 3, 4, 5, 6]
    정답 확인 
    numbers = [1, 2, 3, 4, 5, 6]
for n in numbers:
    if n % 2 == 0:   # 2로 나눈 나머지가 0이면 짝수
        print(n)
    `%`는 나머지를 구하는 연산자입니다. `n % 2 == 0`이 짝수 판별의 공식이에요.
