    Chapter 08. 급식 만족도 조사 분석하기 – 설문 데이터 다루기¶

    🎯 이 장에서 배우는 것¶

    • 설문 응답 데이터를 리스트로 구성하고 빈도수를 분석할 수 있다
    • 조건문으로 그룹을 나눠 그룹별 평균을 비교할 수 있다
    • 분석 결과를 보고 간단한 결론을 내릴 수 있다

    📚 핵심 개념¶

    개념 1: 빈도수 분석¶

    "빈도수 분석은 마치 반에서 손 들기 조사와 같아요"

    선생님이 "떡볶이 좋아하는 사람 손!"이라고 하면, 손든 사람을 세죠. 바로 그게 빈도수(frequency)입니다. 얼마나 많이 등장하는지 세는 것이 빈도수 분석이에요.

    파이썬에서는 딕셔너리({})를 활용해 각 응답이 몇 번 등장했는지 기록합니다.

    # 응답 목록에서 빈도수 세기
responses = ["떡볶이", "피자", "떡볶이", "카레", "피자", "떡볶이"]

count = {}
for item in responses:
    if item in count:
        count[item] += 1
    else:
        count[item] = 1

print(count)  # {'떡볶이': 3, '피자': 2, '카레': 1}

    개념 2: 그룹별 평균 비교¶

    "그룹별 평균 비교는 마치 남녀 대항 줄다리기 점수표와 같아요"

    전체 평균만 보면 놓치는 게 있어요. 남학생 팀, 여학생 팀으로 나눠서 보면 차이가 보이죠. 데이터 분석에서도 조건문으로 그룹을 나눈 다음 각 그룹의 평균을 따로 구하면 더 풍부한 정보를 얻을 수 있습니다.

    flowchart LR A[전체 데이터] --> B{성별 조건} B -->|남학생| C[남학생 점수만 모으기] B -->|여학생| D[여학생 점수만 모으기] C --> E[남학생 평균] D --> F[여학생 평균] E --> G[비교 및 결론] F --> G

    🔨 따라하기¶

    가상의 급식 만족도 설문 데이터를 분석해 볼게요. 20명의 학생이 월~금 급식에 점수(1~5점)를 매겼다고 상상해봐요!

    Step 1: 데이터 준비하기¶

    # 학생 20명의 성별, 요일별 만족도 데이터
gender = ["남","여","남","여","남","여","남","여","남","여",
          "남","여","남","여","남","여","남","여","남","여"]

# 각 학생의 요일별 만족도 [월, 화, 수, 목, 금]
scores = [
    [3,4,5,2,4], [4,5,4,3,5], [2,3,5,4,3], [5,4,3,5,4],
    [3,2,4,3,5], [4,5,5,4,4], [2,4,3,2,5], [5,5,4,5,3],
    [3,3,5,4,4], [4,4,4,3,5], [2,5,3,4,3], [5,3,5,5,4],
    [3,4,4,2,5], [4,5,3,4,4], [2,3,5,3,5], [5,4,4,5,3],
    [3,4,5,4,4], [4,5,4,3,5], [2,3,3,4,3], [5,4,5,5,4]
]

days = ["월", "화", "수", "목", "금"]
print("데이터 준비 완료! 학생 수:", len(scores))

    실행 결과: 

    데이터 준비 완료! 학생 수: 20

    Step 2: 요일별 평균 만족도 구하기¶

    # 요일별 평균 계산
for i in range(5):  # 0=월, 1=화, 2=수, 3=목, 4=금
    day_scores = []
    for student in scores:
        day_scores.append(student[i])
    avg = sum(day_scores) / len(day_scores)
    print(f"{days[i]}요일 평균 만족도: {avg:.2f}점")

    실행 결과: 

    월요일 평균 만족도: 3.45점
화요일 평균 만족도: 3.95점
수요일 평균 만족도: 4.15점
목요일 평균 만족도: 3.75점
금요일 평균 만족도: 4.10점

    Step 3: 가장 인기 있는 급식 요일 찾기¶

    # 요일별 평균을 리스트로 저장
day_avgs = []
for i in range(5):
    day_scores = [student[i] for student in scores]
    day_avgs.append(sum(day_scores) / len(day_scores))

# 최대값 찾기
best_score = max(day_avgs)
best_day = days[day_avgs.index(best_score)]
print(f"🏆 가장 인기 있는 급식 요일: {best_day}요일 ({best_score:.2f}점)")

    실행 결과: 

    🏆 가장 인기 있는 급식 요일: 수요일 (4.15점)

    Step 4: 남녀별 전체 평균 비교하기¶

    # 성별로 나눠 전체 평균 비교
male_all = []
female_all = []

for i in range(len(gender)):
    avg_student = sum(scores[i]) / 5  # 한 학생의 주간 평균
    if gender[i] == "남":
        male_all.append(avg_student)
    else:
        female_all.append(avg_student)

print(f"남학생 평균 만족도: {sum(male_all)/len(male_all):.2f}점")
print(f"여학생 평균 만족도: {sum(female_all)/len(female_all):.2f}점")

    실행 결과: 

    남학생 평균 만족도: 3.50점
여학생 평균 만족도: 4.20점

    Step 5: 선호 메뉴 빈도수 Top 3 찾기¶

    # 20명이 가장 좋아하는 급식 메뉴 응답
menu_votes = ["피자","떡볶이","피자","카레","짜장면","피자","떡볶이",
              "카레","피자","짜장면","떡볶이","피자","카레","짜장면",
              "피자","떡볶이","카레","피자","짜장면","떡볶이"]

# 빈도수 세기
count = {}
for menu in menu_votes:
    count[menu] = count.get(menu, 0) + 1

# 많은 순서로 정렬
sorted_menu = sorted(count.items(), key=lambda x: x[1], reverse=True)

print("🍽️ 선호 메뉴 순위")
for rank, (menu, cnt) in enumerate(sorted_menu[:3], start=1):
    print(f"  {rank}위: {menu} ({cnt}표)")

    실행 결과: 

    🍽️ 선호 메뉴 순위
  1위: 피자 (7표)
  2위: 떡볶이 (5표)
  3위: 카레 (4표)

    📝 전체 코드¶

    # =============================================
# 급식 만족도 조사 분석기
# =============================================

gender = ["남","여","남","여","남","여","남","여","남","여",
          "남","여","남","여","남","여","남","여","남","여"]

scores = [
    [3,4,5,2,4], [4,5,4,3,5], [2,3,5,4,3], [5,4,3,5,4],
    [3,2,4,3,5], [4,5,5,4,4], [2,4,3,2,5], [5,5,4,5,3],
    [3,3,5,4,4], [4,4,4,3,5], [2,5,3,4,3], [5,3,5,5,4],
    [3,4,4,2,5], [4,5,3,4,4], [2,3,5,3,5], [5,4,4,5,3],
    [3,4,5,4,4], [4,5,4,3,5], [2,3,3,4,3], [5,4,5,5,4]
]
days = ["월", "화", "수", "목", "금"]

# [1] 요일별 평균 & 최고 요일
print("=== 요일별 만족도 ===")
day_avgs = []
for i in range(5):
    day_scores = [student[i] for student in scores]
    avg = sum(day_scores) / len(day_scores)
    day_avgs.append(avg)
    print(f"{days[i]}요일: {avg:.2f}점")

best_day = days[day_avgs.index(max(day_avgs))]
print(f"\n🏆 최고 인기 요일: {best_day}요일\n")

# [2] 남녀별 평균 비교
print("=== 남녀별 만족도 ===")
male_all, female_all = [], []
for i in range(len(gender)):
    avg_s = sum(scores[i]) / 5
    if gender[i] == "남":
        male_all.append(avg_s)
    else:
        female_all.append(avg_s)
print(f"남학생: {sum(male_all)/len(male_all):.2f}점")
print(f"여학생: {sum(female_all)/len(female_all):.2f}점\n")

# [3] 선호 메뉴 Top 3
print("=== 선호 메뉴 Top 3 ===")
menu_votes = ["피자","떡볶이","피자","카레","짜장면","피자","떡볶이",
              "카레","피자","짜장면","떡볶이","피자","카레","짜장면",
              "피자","떡볶이","카레","피자","짜장면","떡볶이"]
count = {}
for menu in menu_votes:
    count[menu] = count.get(menu, 0) + 1
sorted_menu = sorted(count.items(), key=lambda x: x[1], reverse=True)
for rank, (menu, cnt) in enumerate(sorted_menu[:3], start=1):
    print(f"  {rank}위: {menu} ({cnt}표)")

    ⚠️ 주의할 점¶

    1. 인덱스와 요일이 항상 짝을 이뤄야 해요 scores의 각 행에서 [0]은 월요일, [1]은 화요일... 이 순서가 흐트러지면 분석 결과가 완전히 엉터리가 됩니다. 데이터를 만들 때 순서를 꼼꼼히 확인하는 습관을 들이세요!

    2. count.get(menu, 0)의 의미를 기억하세요 딕셔너리에서 없는 키를 조회하면 오류가 납니다. get(키, 기본값)을 쓰면 키가 없을 때 기본값(0)을 돌려줘서 안전하게 빈도수를 셀 수 있어요.

    ✅ 점검하기¶

    Q1. 빈도수 분석이란 무엇인가요?

    정답 확인 데이터에서 각 항목이 **몇 번 등장하는지 세는 것**입니다. 예를 들어 20명의 선호 메뉴 응답에서 "피자"가 몇 번 나왔는지 세는 게 빈도수 분석이에요.

    Q2. 아래 코드에서 reverse=True를 빼면 결과가 어떻게 달라질까요? 

    sorted_menu = sorted(count.items(), key=lambda x: x[1], reverse=True)

    정답 확인 `reverse=True`를 빼면 **오름차순(작은 순서)**으로 정렬됩니다. 즉, 가장 적게 투표된 메뉴부터 나오게 되어 Top 3를 뽑으려면 뒤에서 3개를 가져와야 해요. 내림차순으로 정렬해야 `[:3]`으로 상위 3개를 바로 뽑을 수 있습니다.

    Q3. 남학생이 10명, 여학생이 10명인데 남학생 평균이 3.50점, 여학생 평균이 4.20점이라면, 어떤 결론을 내릴 수 있을까요?

    정답 확인 "이 학교 급식에 대한 만족도는 **여학생(4.20점)이 남학생(3.50점)보다 0.70점 높다**"고 결론 내릴 수 있어요. 단, 표본이 20명으로 적으므로 '이 반의 경향'이지 전체 학교를 대표하지는 않는다는 점도 함께 언급하면 더 좋은 분석이 됩니다!
