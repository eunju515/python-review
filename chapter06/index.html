    Chapter 06. 더 깊이 요약하자 – 범위, 빈도수, 정렬 함수 만들기¶

    Part 2 | 도구 장착 – 함수로 나만의 분석 도구 만들기

    🎯 이 장에서 배우는 것¶

    • 최댓값과 최솟값의 차이(범위)를 구하는 my_range 함수를 작성할 수 있다
    • 특정 값이 몇 번 등장하는지 세는 my_frequency 함수를 작성할 수 있다
    • 버블 정렬 원리를 이해하고 my_sort 함수를 작성할 수 있다

    📚 핵심 개념¶

    개념 1: 범위(Range) – 데이터가 얼마나 퍼져 있나?¶

    범위는 마치 온도계의 눈금 폭과 같아요. 오늘 최고기온이 32도, 최저기온이 18도라면 일교차는 14도입니다. 그 "폭"이 바로 범위예요.

    정확한 정의: 범위 = 최댓값 − 최솟값

    평균이 같아도 범위가 다르면 데이터의 모습은 완전히 달라집니다.

    예를 들어 두 반의 급식 만족도 평균이 모두 3점이라도,

    • A반: 점수가 2, 3, 3, 3, 4 → 범위 = 2 (비교적 고른 편)
    • B반: 점수가 1, 1, 3, 5, 5 → 범위 = 4 (의견이 극단적으로 나뉨)

    범위가 크면 의견 차이가 크다는 뜻이에요! 📊

    개념 2: 버블 정렬 – 옆 친구와 자리 바꾸기¶

    버블 정렬은 마치 키 순서로 줄 세우는 체육 시간과 같아요. 옆에 있는 두 명씩 키를 비교해서 큰 사람이 뒤로 가도록 계속 자리를 바꿉니다. 이 과정을 반복하면 결국 가장 큰 사람이 맨 뒤로 "거품처럼 떠올라요."

    flowchart LR A["[3, 1, 4, 2]"] -->|"3>1? 교환"| B["[1, 3, 4, 2]"] B -->|"3<4? 유지"| C["[1, 3, 4, 2]"] C -->|"4>2? 교환"| D["[1, 3, 2, 4]"] D -->|"1차 통과 완료"| E["4가 맨 뒤로 확정!"]

    이 과정을 리스트 길이만큼 반복하면 완전히 정렬됩니다.

    🔨 따라하기¶

    오늘 사용할 데이터: 급식 만족도 점수 (1~5점)

    scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]

    Step 1: my_range 함수 만들기¶

    def my_range(data):
    maximum = data[0]
    minimum = data[0]
    for value in data:
        if value > maximum:
            maximum = value
        if value < minimum:
            minimum = value
    return maximum - minimum  # 최댓값 - 최솟값

scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]
print("범위:", my_range(scores))

    실행 결과: 

    범위: 4

    Step 2: my_frequency 함수 만들기¶

    특정 값이 리스트에 몇 번 나오는지 셉니다.

    def my_frequency(data, target):
    count = 0
    for value in data:
        if value == target:
            count += 1
    return count

scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]
print("5점 빈도수:", my_frequency(scores, 5))
print("3점 빈도수:", my_frequency(scores, 3))

    실행 결과: 

    5점 빈도수: 3
3점 빈도수: 3

    Step 3: my_sort 함수 만들기 (버블 정렬)¶

    def my_sort(data):
    result = data[:]          # 원본 보호를 위해 복사
    n = len(result)
    for i in range(n):        # 전체 통과 횟수
        for j in range(n - 1 - i):   # 이미 정렬된 뒤쪽은 건너뜀
            if result[j] > result[j + 1]:
                result[j], result[j + 1] = result[j + 1], result[j]  # 교환!
    return result

scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]
print("정렬 결과:", my_sort(scores))

    실행 결과: 

    정렬 결과: [1, 2, 2, 3, 3, 3, 4, 5, 5, 5]

    💡 result[j], result[j+1] = result[j+1], result[j] 는 파이썬의 동시 교환(swap) 문법입니다. 임시 변수 없이 두 값을 바꿀 수 있어요!

    Step 4: 모든 점수 구간의 빈도수 한눈에 보기¶

    scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]
for point in [1, 2, 3, 4, 5]:
    print(f"{point}점: {my_frequency(scores, point)}번")

    실행 결과: 

    1점: 1번
2점: 2번
3점: 3번
4점: 1번
5점: 3번

    📝 전체 코드¶

    # ── 함수 정의 ──────────────────────────────────

def my_range(data):
    """최댓값 - 최솟값 (범위)"""
    maximum = data[0]
    minimum = data[0]
    for value in data:
        if value > maximum:
            maximum = value
        if value < minimum:
            minimum = value
    return maximum - minimum

def my_frequency(data, target):
    """target 값이 몇 번 등장하는지 반환"""
    count = 0
    for value in data:
        if value == target:
            count += 1
    return count

def my_sort(data):
    """버블 정렬로 오름차순 정렬된 새 리스트 반환"""
    result = data[:]
    n = len(result)
    for i in range(n):
        for j in range(n - 1 - i):
            if result[j] > result[j + 1]:
                result[j], result[j + 1] = result[j + 1], result[j]
    return result

# ── 실행 ───────────────────────────────────────

scores = [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]

print("=== 급식 만족도 분석 ===")
print("데이터:", scores)
print("범위:", my_range(scores))
print("정렬:", my_sort(scores))
print()
print("── 점수별 빈도수 ──")
for point in [1, 2, 3, 4, 5]:
    print(f"  {point}점: {my_frequency(scores, point)}번")

    실행 결과: 

    === 급식 만족도 분석 ===
데이터: [3, 5, 2, 5, 1, 3, 4, 5, 2, 3]
범위: 4
정렬: [1, 2, 2, 3, 3, 3, 4, 5, 5, 5]

── 점수별 빈도수 ──
  1점: 1번
  2점: 2번
  3점: 3번
  4점: 1번
  5점: 3번

    ⚠️ 주의할 점¶

    ① 원본 리스트를 지키려면 복사하세요 my_sort 함수 안에서 result = data[:]로 복사한 이유가 있어요. 만약 result = data라고 쓰면 원본 scores도 함께 바뀌어 버립니다. 나중에 원본이 필요한 상황이 오면 낭패예요!

    ② 빈 리스트에 주의하세요 my_range와 my_sort는 data[0]에 접근하는 순간 리스트가 비어 있으면 오류가 납니다. 실제 프로그램에서는 if len(data) == 0: return None 같은 방어 코드를 추가하면 더 안전해요.

    ✅ 점검하기¶

    1. scores = [4, 1, 3, 1, 2]일 때 my_range(scores)의 결과는?

    정답 확인 최댓값 4, 최솟값 1 → **4 − 1 = 3**

    2. 버블 정렬에서 result[j], result[j+1] = result[j+1], result[j]가 실행되는 조건은 언제인가요?

    정답 확인 `result[j] > result[j+1]`일 때, 즉 **앞의 값이 뒤의 값보다 클 때** 두 값을 교환합니다. 오름차순(작은 것부터 큰 순서)으로 정렬하기 위해서예요.

    3. my_frequency(scores, 3)이 2를 반환하려면 scores 안에 숫자 3이 몇 개 있어야 하나요?

    정답 확인 **2개**. `my_frequency`는 `target`과 일치하는 요소를 하나씩 세므로, 3이 정확히 2번 들어 있을 때 2를 반환합니다.
