    Chapter 05. 숫자로 요약하자 – 합계, 평균, 최댓값, 최솟값 함수 만들기¶

    🎯 이 장에서 배우는 것¶

    • 반복문을 활용하여 리스트의 합계와 평균을 구하는 함수를 직접 작성할 수 있다.
    • 리스트에서 최댓값과 최솟값을 찾는 함수를 직접 작성할 수 있다.
    • 기초 통계값(합계, 평균, 최댓값, 최솟값)이 데이터를 요약하는 역할임을 이해할 수 있다.

    📚 핵심 개념¶

    개념 1: 합계와 평균 – 숫자를 하나로 모으기¶

    "합계를 구하는 것은 마치 저금통에 동전을 하나씩 넣는 것과 같아요."

    리스트에 숫자가 10개, 100개 있어도 결국 우리가 알고 싶은 건 단 하나의 대표값입니다. 합계(sum) 는 모든 값을 더한 총합이고, 평균(average) 은 그 합계를 개수로 나눈 값이에요.

    아래 흐름을 보면 이해가 쉬워요:

    flowchart LR A["리스트\n[80, 90, 75, 95, 85]"] --> B["누적 합산\n0→80→170→245→340→425"] B --> C["합계: 425"] C --> D["÷ 개수(5)"] D --> E["평균: 85.0"]

    핵심 아이디어는 누적 변수입니다. total = 0으로 시작해서, 리스트를 돌며 하나씩 더해가는 방식이에요.

    개념 2: 최댓값과 최솟값 – 하나씩 비교하며 챔피언 찾기¶

    "최댓값을 찾는 것은 마치 씨름 대회에서 이긴 사람이 계속 다음 도전자를 맞이하는 것과 같아요."

    첫 번째 선수가 잠정 챔피언이 됩니다. 그다음 선수와 비교해서 더 강하면 교체! 이 과정을 끝까지 반복하면 최종 챔피언(최댓값)이 남아요.

    flowchart LR A["champion = 80"] --> B{"90 > 80?"} B -->|"Yes"| C["champion = 90"] C --> D{"75 > 90?"} D -->|"No"| E["champion = 90 유지"] E --> F{"95 > 90?"} F -->|"Yes"| G["champion = 95"] G --> H["최종 최댓값: 95"]

    최솟값은 반대로, 더 작은 값이 나오면 교체하는 방식입니다.

    🔨 따라하기¶

    Step 1: 합계 함수 my_sum 만들기¶

    코드: 

    def my_sum(numbers):
    total = 0                  # 저금통을 0원으로 시작
    for num in numbers:
        total = total + num    # 동전 하나씩 넣기
    return total

    실행 결과: 

    scores = [80, 90, 75, 95, 85]
print(my_sum(scores))  # → 425

    Step 2: 평균 함수 my_average 만들기¶

    코드: 

    def my_average(numbers):
    total = my_sum(numbers)         # 앞에서 만든 함수 재사용!
    count = len(numbers)            # 개수 구하기
    return total / count

    실행 결과: 

    85.0

    💡 포인트! 함수를 만들어두면 다른 함수 안에서도 재사용할 수 있어요. my_sum을 my_average 안에서 그대로 호출했습니다.

    Step 3: 최댓값 함수 my_max, 최솟값 함수 my_min 만들기¶

    코드: 

    def my_max(numbers):
    champion = numbers[0]          # 첫 번째 값이 잠정 챔피언
    for num in numbers:
        if num > champion:
            champion = num         # 더 크면 교체!
    return champion

def my_min(numbers):
    weakest = numbers[0]           # 첫 번째 값이 잠정 최솟값
    for num in numbers:
        if num < weakest:
            weakest = num          # 더 작으면 교체!
    return weakest

    실행 결과: 

    print(my_max(scores))  # → 95
print(my_min(scores))  # → 75

    Step 4: 네 함수를 모두 활용해 성적 요약 출력하기¶

    코드: 

    scores = [80, 90, 75, 95, 85, 70, 88, 92, 78, 83]

print("=== 수학 성적 요약 ===")
print("합계:", my_sum(scores))
print("평균:", my_average(scores))
print("최고점:", my_max(scores))
print("최저점:", my_min(scores))

    실행 결과: 

    === 수학 성적 요약 ===
합계: 836
평균: 83.6
최고점: 95
최저점: 70

    📝 전체 코드¶

    # ---- 네 가지 통계 함수 정의 ----

def my_sum(numbers):
    total = 0
    for num in numbers:
        total = total + num
    return total

def my_average(numbers):
    total = my_sum(numbers)
    count = len(numbers)
    return total / count

def my_max(numbers):
    champion = numbers[0]
    for num in numbers:
        if num > champion:
            champion = num
    return champion

def my_min(numbers):
    weakest = numbers[0]
    for num in numbers:
        if num < weakest:
            weakest = num
    return weakest

# ---- 실제 데이터에 적용 ----

scores = [80, 90, 75, 95, 85, 70, 88, 92, 78, 83]

print("=== 수학 성적 요약 ===")
print("합계:", my_sum(scores))
print("평균:", my_average(scores))
print("최고점:", my_max(scores))
print("최저점:", my_min(scores))

    ⚠️ 주의할 점¶

    1. 빈 리스트를 넣으면 오류가 발생해요!

    my_max와 my_min에서 numbers[0]으로 첫 번째 값을 가져오는데, 리스트가 비어 있으면 IndexError가 납니다. 지금은 "값이 있는 리스트만 사용한다"고 약속하고 넘어가요. 나중에 예외 처리를 배우면 해결할 수 있어요!

    2. my_average에서 결과가 정수처럼 보여도 소수점이 있을 수 있어요.

    나눗셈(/)은 항상 실수(float)를 반환합니다. 836 / 10의 결과는 83이 아니라 83.6이에요. 정수만 필요하다면 //(정수 나눗셈)를 사용하세요.

    ✅ 점검하기¶

    Q1. my_sum([1, 2, 3, 4, 5])의 결과는 무엇인가요?

    정답 확인 `total`이 0 → 1 → 3 → 6 → 10 → 15로 누적됩니다. 결과는 **15**입니다.

    Q2. my_max 함수에서 champion = numbers[0]으로 시작하는 이유는 무엇인가요?

    정답 확인 비교 기준이 되는 **초기값**이 필요하기 때문입니다. 첫 번째 값을 잠정 챔피언으로 설정하고, 나머지 값들과 하나씩 비교하며 더 큰 값으로 교체해 나갑니다. 초기값 없이 비교를 시작할 수 없어요.

    Q3. 아래 코드의 출력 결과를 예측해보세요.

    temps = [28, 31, 25, 33, 29]
print(my_average(temps))
    정답 확인 합계: `28 + 31 + 25 + 33 + 29 = 146`, 개수: `5` 결과: **`29.2`**
