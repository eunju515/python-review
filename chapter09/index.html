    Chapter 09. 나만의 데이터 프로젝트 – 분석하고 발표하기¶

    Part 3: 실전 체험 – 데이터분석, 이런 거구나!

    🎯 이 장에서 배우는 것¶

    • 데이터셋을 선택하고 '내가 궁금한 질문'을 스스로 세울 수 있다
    • 지금까지 배운 파이썬 문법으로 질문에 답하는 코드를 작성할 수 있다
    • 분석 결과를 한 문장 인사이트로 정리하고 발표할 수 있다

    📚 핵심 개념¶

    개념 1: 데이터 분석의 전체 흐름¶

    데이터 분석은 마치 탐정이 사건을 푸는 과정과 같아요.

    탐정은 "누가 했을까?"라는 질문에서 시작해서, 단서(데이터)를 모으고, 분석해서, 최종적으로 범인(인사이트)을 밝혀냅니다.

    데이터 분석도 딱 4단계입니다.

    flowchart LR A["❓ 질문\n무엇이 궁금한가?"] --> B["📦 데이터\n숫자를 준비한다"] B --> C["🔍 분석\n코드로 계산한다"] C --> D["💡 해석\n한 문장으로 정리"]

    이 4단계가 바로 데이터 분석의 전체 과정입니다. 오늘은 이 흐름을 처음부터 끝까지 혼자 완주해보는 시간이에요! 🏃

    개념 2: 한 줄 인사이트¶

    분석에서 가장 중요한 마지막 단계는 "그래서 뭘 알게 됐어?"를 한 문장으로 말하는 것이에요.

    이걸 인사이트(insight) 라고 부릅니다. '안을 들여다본다'는 뜻이에요.

    좋은 인사이트는 이렇게 생겼어요.

    • 🚫 나쁜 예: "평균이 52.3이었다" (숫자만 나열)
    • ✅ 좋은 예: "조회수가 가장 높은 요일은 금요일로, 월요일보다 2배 많다"

    숫자 → 의미 로 바꾸는 게 핵심입니다. 숫자를 보고 "그래서 어떤 의미인가?"를 항상 물어보세요.

    🔨 따라하기¶

    오늘은 프로야구 팀 승률 데이터를 예시로 미니 프로젝트를 완성합니다. 아래 5단계를 차례로 따라해보세요.

    Step 1: 데이터 준비하기¶

    코드: 

    # 프로야구 팀 데이터
teams = ["Lions", "Bears", "Tigers", "Eagles", "Heroes"]
wins  = [82, 75, 68, 61, 54]
games = [144, 144, 144, 144, 144]

    실행 결과: 

    (출력 없음 - 데이터를 변수에 담은 것)

    Step 2: 나의 분석 질문 정하기¶

    코드를 작성하기 전에, 종이에 질문을 먼저 써보세요. 예를 들면:

    • "가장 승률이 높은 팀은 어디일까?"
    • "평균 승률은 얼마일까?"
    • "승률 50% 이상인 팀은 몇 팀일까?"

    💬 오늘 나의 질문: "가장 승률이 높은 팀은 어디이고, 평균 승률은 얼마일까?"

    Step 3: 분석 함수 작성하기¶

    코드: 

    # 승률을 계산하는 함수
def calc_rate(wins, games):
    return round(wins / games * 100, 1)  # 소수점 1자리

# 각 팀 승률 리스트 만들기
rates = []
for i in range(len(teams)):
    rates.append(calc_rate(wins[i], games[i]))

    실행 결과: 

    (출력 없음 - rates 리스트에 승률이 저장됨)

    Step 4: 결과 출력하기¶

    코드: 

    print("=== 팀별 승률 ===")
for i in range(len(teams)):
    print(f"{teams[i]}: {rates[i]}%")

# 최고 승률 팀 찾기
best_idx = rates.index(max(rates))
avg_rate = round(sum(rates) / len(rates), 1)

print(f"\n🏆 최고 승률 팀: {teams[best_idx]} ({rates[best_idx]}%)")
print(f"📊 평균 승률: {avg_rate}%")

    실행 결과: 

    === 팀별 승률 ===
Lions: 56.9%
Bears: 52.1%
Tigers: 47.2%
Eagles: 42.4%
Heroes: 37.5%

🏆 최고 승률 팀: Lions (56.9%)
📊 평균 승률: 47.2%

    Step 5: 한 줄 인사이트 작성하기¶

    코드: 

    # 인사이트 출력
print("\n💡 인사이트:")
print(f"Lions가 {rates[best_idx]}%로 1위이며, 평균({avg_rate}%)보다 약 10%p 앞서 있다.")

    실행 결과: 

    💡 인사이트:
Lions가 56.9%로 1위이며, 평균(47.2%)보다 약 10%p 앞서 있다.

    📝 전체 코드¶

    # ✅ 미니 프로젝트: 프로야구 팀 승률 분석

# Step 1. 데이터 준비
teams = ["Lions", "Bears", "Tigers", "Eagles", "Heroes"]
wins  = [82, 75, 68, 61, 54]
games = [144, 144, 144, 144, 144]

# Step 2. 분석 함수 정의
def calc_rate(wins, games):
    return round(wins / games * 100, 1)

# Step 3. 승률 계산
rates = []
for i in range(len(teams)):
    rates.append(calc_rate(wins[i], games[i]))

# Step 4. 결과 출력
print("=== 팀별 승률 ===")
for i in range(len(teams)):
    print(f"{teams[i]}: {rates[i]}%")

best_idx = rates.index(max(rates))
avg_rate = round(sum(rates) / len(rates), 1)

print(f"\n🏆 최고 승률 팀: {teams[best_idx]} ({rates[best_idx]}%)")
print(f"📊 평균 승률: {avg_rate}%")

# Step 5. 한 줄 인사이트
print("\n💡 인사이트:")
print(f"Lions가 {rates[best_idx]}%로 1위이며, 평균({avg_rate}%)보다 약 10%p 앞서 있다.")

    ⚠️ 주의할 점¶

    ① 질문 없이 코드부터 짜지 마세요 코드를 먼저 작성하고 싶은 마음이 굴뚝같겠지만, 질문이 없으면 어떤 코드를 써야 할지 방향을 잃게 됩니다. 반드시 "내가 무엇을 알고 싶은가?"를 먼저 종이에 쓰고 시작하세요.

    ② 인사이트는 숫자가 아니라 의미입니다 print(max(rates)) 로 숫자만 출력하는 건 절반짜리 분석이에요. "어떤 팀이", "얼마나", "다른 팀과 비교해서 어떤지"까지 문장으로 연결해야 진짜 인사이트가 됩니다.

    ✅ 점검하기¶

    1. 데이터 분석의 4단계를 순서대로 말할 수 있나요?

    정답 확인 질문 → 데이터 준비 → 분석(코드 작성) → 해석(인사이트 도출)

    2. 아래 두 문장 중 더 좋은 인사이트는 무엇이고, 그 이유는? - (가) "최댓값은 2100000이었다" - (나) "FunnyClip 채널이 가장 조회수가 많으며, 꼴찌 채널보다 약 23배 차이가 난다"

    정답 확인 (나)가 좋은 인사이트입니다. 단순히 숫자를 나열하지 않고, 채널 이름(맥락)과 비교값(의미)을 포함해 "그래서 어떻다"는 결론을 담고 있기 때문입니다.

    3. rates.index(max(rates)) 는 무엇을 반환하나요?

    정답 확인 `max(rates)` 로 가장 큰 값을 찾고, `.index()` 로 그 값이 있는 **인덱스(위치 번호)** 를 반환합니다. 이 인덱스를 `teams[best_idx]` 처럼 사용하면 해당 팀 이름을 가져올 수 있습니다.
