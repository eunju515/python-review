    Chapter 04. 반복 작업은 함수에게 – 함수 정의 복습¶

    Part 2: 도구 장착 – 함수로 나만의 분석 도구 만들기

    🎯 이 장에서 배우는 것¶

    • def 키워드로 함수를 정의하고, 매개변수와 return의 역할을 설명할 수 있다.
    • 직접 정의한 함수를 호출하여 결과를 변수에 저장하고 활용할 수 있다.
    • 같은 계산을 여러 번 해야 할 때 함수로 묶으면 편리하다는 점을 체감할 수 있다.

    📚 핵심 개념¶

    개념 1: 함수는 자판기다¶

    🥤 "함수는 마치 자판기와 같아요. 동전(매개변수)을 넣으면, 내가 원하는 음료(return 값)가 나옵니다."

    정확한 정의: 함수란 특정 작업을 수행하는 코드 묶음입니다. 한 번 만들어두면 언제든 이름만 불러서 재사용할 수 있습니다.

    함수가 없다면 어떤 일이 생길까요?

    국어, 영어, 수학 점수 합계를 각각 구해야 한다고 해봅시다. 함수 없이 쓰면 이렇게 됩니다:

    korean_total = 90 + 85 + 78 + 92
english_total = 70 + 88 + 95 + 60
math_total = 80 + 75 + 90 + 85

    지금은 괜찮아 보이지만, 과목이 10개로 늘어나면? 😰 같은 덧셈 패턴을 10번 반복해야 합니다. 이럴 때 함수가 빛을 발합니다!

    개념 2: 함수의 세 가지 구성요소¶

    함수를 만드는 데는 세 가지가 필요합니다.

    flowchart LR A["🪙 매개변수\n(입력값)"] --> B["⚙️ 함수 본문\n(처리)"] B --> C["📦 return\n(출력값)"] style A fill:#FFF3CD,stroke:#FFC107 style B fill:#D1ECF1,stroke:#17A2B8 style C fill:#D4EDDA,stroke:#28A745

    ① def – 함수를 선언하는 키워드

    def는 "define(정의하다)"의 줄임말입니다. "이런 이름의 함수를 만들겠다"고 파이썬에게 알리는 신호입니다.

    ② 매개변수(parameter) – 함수가 받는 입력값

    자판기에 넣는 동전처럼, 함수가 일을 하려면 재료가 필요합니다. 그 재료를 매개변수라고 부릅니다.

    ③ return – 함수가 돌려주는 결과

    return이 없으면 자판기에서 음료가 안 나오는 것과 같습니다. 결과를 밖으로 꺼내주는 역할을 합니다.

    # 함수의 기본 구조
def 함수이름(매개변수):
    처리할 코드
    return 결과값

    🔨 따라하기¶

    Step 1: 가장 간단한 함수 – 두 수 더하기¶

    코드:

    def add(a, b):       # a와 b를 받아서
    result = a + b   # 더하고
    return result    # 결과를 돌려준다

# 함수 호출하기
print(add(3, 5))     # 8
print(add(10, 20))   # 30

    실행 결과: 

    8
30

    add(3, 5)라고 쓰면 a=3, b=5가 됩니다. 함수 안에서 3 + 5 = 8을 계산한 뒤 return으로 내보냅니다. 🎉

    Step 2: return 값을 변수에 저장하기¶

    코드:

    def add(a, b):
    return a + b

my_sum = add(10, 20)   # 결과를 변수에 저장
print(my_sum)          # 나중에 꺼내 쓸 수 있다
print(my_sum * 2)      # 활용도 가능!

    실행 결과: 

    30
60

    return 값은 변수에 담아두면 나중에 마음껏 활용할 수 있습니다.

    Step 3: 리스트를 받아 합계를 돌려주는 함수¶

    이제 진짜 유용한 함수를 만들어봅시다! 숫자 리스트를 받아서 총합을 계산해 돌려주는 함수입니다.

    코드:

    def my_sum(numbers):      # 리스트를 통째로 받는다
    total = 0
    for n in numbers:     # 리스트 요소를 하나씩 꺼내서
        total = total + n # 누적해서 더한다
    return total          # 최종 합계를 돌려준다

# 이제 어떤 리스트든 넣으면 합계가 나온다!
korean = [90, 85, 78, 92]
english = [70, 88, 95, 60]

print(my_sum(korean))    # 345
print(my_sum(english))   # 313

    실행 결과: 

    345
313

    함수를 한 번 만들었더니, 과목이 몇 개가 생겨도 같은 함수를 계속 재사용할 수 있습니다. 💪

    📝 전체 코드¶

    # ① 두 수를 더하는 함수
def add(a, b):
    return a + b

# ② 리스트의 합계를 구하는 함수
def my_sum(numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total

# --- 함수 활용 ---

# 기본 덧셈
print(add(3, 5))        # 8

# 결과를 변수에 저장
my_result = add(100, 200)
print(my_result)        # 300

# 리스트 합계
korean = [90, 85, 78, 92]
english = [70, 88, 95, 60]

korean_total = my_sum(korean)
english_total = my_sum(english)

print(korean_total)     # 345
print(english_total)    # 313

# 어느 과목 총점이 더 높은가?
if korean_total > english_total:
    print("국어 총점이 더 높습니다!")
else:
    print("영어 총점이 더 높습니다!")

    ⚠️ 주의할 점¶

    ① 들여쓰기를 반드시 맞춰야 합니다

    파이썬은 들여쓰기로 함수 내부를 구분합니다. def 아래 줄은 스페이스 4칸 들여써야 합니다. 들여쓰기가 어긋나면 IndentationError가 발생합니다.

    # ❌ 잘못된 예
def add(a, b):
return a + b      # 들여쓰기 없음 → 오류!

# ✅ 올바른 예
def add(a, b):
    return a + b  # 4칸 들여쓰기

    ② return을 빠뜨리면 None이 돌아옵니다

    return을 쓰지 않으면 함수는 계산은 하지만 아무것도 돌려주지 않습니다. 결과를 변수에 저장하려면 return을 꼭 써주세요!

    ✅ 점검하기¶

    Q1. 아래 함수를 호출하면 무엇이 출력될까요?

    def greet(name):
    return "안녕하세요, " + name + "님!"

message = greet("지수")
print(message)
    정답 확인 **출력:** `안녕하세요, 지수님!` `greet("지수")`를 호출하면 매개변수 `name`에 `"지수"`가 들어가고, `return`으로 완성된 문자열이 나옵니다. 그 값이 `message`에 저장된 뒤 출력됩니다.

    Q2. my_sum([1, 2, 3, 4, 5])를 호출하면 어떤 값이 반환될까요?

    정답 확인 **반환값:** `15` `1 + 2 + 3 + 4 + 5 = 15`입니다. `for` 반복문이 리스트를 순서대로 돌며 `total`에 누적합니다.

    🏆 도전 과제: 리스트를 받아 요소 개수를 반환하는 my_count 함수를 직접 작성해보세요! (힌트: total = 0에서 시작해서, 요소를 만날 때마다 total = total + 1)

    정답 확인 
    def my_count(numbers):
    total = 0
    for n in numbers:
        total = total + 1  # 요소를 만날 때마다 1씩 증가
    return total

scores = [90, 85, 78, 92, 88]
print(my_count(scores))  # 5
