    Chapter 02. 데이터를 한 줄로 모아보자 – 리스트 복습¶

    🎯 이 장에서 배우는 것¶

    • 리스트를 만들고, 인덱싱·슬라이싱으로 원하는 값을 꺼낼 수 있다
    • append()로 값을 추가하고, 인덱스로 값을 수정·삭제할 수 있다
    • len() 함수로 리스트 길이를 구하고, 데이터 묶음 개념을 이해할 수 있다

    📚 핵심 개념¶

    개념 1: 리스트 – 한 줄 사물함¶

    리스트는 마치 번호가 붙은 한 줄 사물함과 같아요.

    학교 사물함을 떠올려보세요. 1번 칸, 2번 칸, 3번 칸… 각 칸에 다른 물건을 넣을 수 있죠. 파이썬 리스트도 똑같습니다. 여러 값을 순서대로 한 변수에 담아두는 도구예요.

    변수 하나에 값 하나만 넣으면, 30명 학생의 점수를 저장하려면 변수가 30개 필요합니다. 리스트를 쓰면 단 한 줄로 해결돼요!

    # 변수를 따로따로 쓰면... 😓
score1 = 85
score2 = 90
score3 = 78

# 리스트를 쓰면 한 줄로! 😊
scores = [85, 90, 78]

    리스트는 대괄호 [ ] 안에 값을 쉼표로 구분해서 넣습니다.

    리스트이름 = [값1, 값2, 값3, ...]

    개념 2: 인덱싱과 슬라이싱 – 원하는 칸 열기¶

    리스트에서 특정 값을 꺼내려면 인덱스(번호) 를 사용합니다.

    사물함 번호로 원하는 칸을 여는 것처럼요!

    ⚠️ 파이썬의 인덱스는 0부터 시작합니다. 이게 처음엔 헷갈리는데, 아래 그림을 보면 금방 익숙해져요.

    graph LR A["급식점수 리스트"] --> B subgraph B["scores = [4, 5, 3, 4, 2]"] direction LR B0["4\n인덱스 0"] B1["5\n인덱스 1"] B2["3\n인덱스 2"] B3["4\n인덱스 3"] B4["2\n인덱스 4"] end
    • 인덱싱: 값 하나를 꺼낼 때 → 리스트[인덱스]
    • 슬라이싱: 범위로 잘라낼 때 → 리스트[시작:끝] (끝 인덱스는 포함 안 됨)
    scores = [4, 5, 3, 4, 2]

print(scores[0])    # 4  (첫 번째 값)
print(scores[1])    # 5  (두 번째 값)
print(scores[-1])   # 2  (맨 마지막 값, 음수 인덱스!)

print(scores[0:3])  # [4, 5, 3]  (0번부터 2번까지)

    🔨 따라하기¶

    Step 1: 급식 만족도 리스트 만들기¶

    일주일(월~금) 급식 만족도 점수를 리스트로 만들어봅시다.

    코드: 

    # 월~금 급식 만족도 점수 (1~5점)
lunch_score = [4, 5, 3, 4, 2]
print(lunch_score)

    실행 결과: 

    [4, 5, 3, 4, 2]

    Step 2: 인덱싱으로 특정 요일 꺼내기¶

    코드: 

    lunch_score = [4, 5, 3, 4, 2]

# 월요일(0번), 화요일(1번) 점수 출력
print("월요일 점수:", lunch_score[0])
print("화요일 점수:", lunch_score[1])
print("금요일 점수:", lunch_score[-1])  # 마지막 요일

    실행 결과: 

    월요일 점수: 4
화요일 점수: 5
금요일 점수: 2

    Step 3: 값 수정하고 append로 추가하기¶

    코드: 

    lunch_score = [4, 5, 3, 4, 2]

# 수요일(2번) 점수가 잘못 입력됐어요 → 수정
lunch_score[2] = 5
print("수정 후:", lunch_score)

# 토요일 특별 급식 점수 추가
lunch_score.append(4)
print("추가 후:", lunch_score)

    실행 결과: 

    수정 후: [4, 5, 5, 4, 2]
추가 후: [4, 5, 5, 4, 2, 4]

    Step 4: len()으로 길이 구하기¶

    코드: 

    lunch_score = [4, 5, 3, 4, 2]

print("총 며칠의 데이터?", len(lunch_score))  # 5

    실행 결과: 

    총 며칠의 데이터? 5

    📝 전체 코드¶

    # 일주일 급식 만족도 점수 리스트
lunch_score = [4, 5, 3, 4, 2]

# 인덱싱으로 특정 요일 꺼내기
print("월요일 점수:", lunch_score[0])
print("화요일 점수:", lunch_score[1])
print("금요일 점수:", lunch_score[-1])

# 슬라이싱으로 앞 3일 꺼내기
print("월~수 점수:", lunch_score[0:3])

# 수요일 점수 수정
lunch_score[2] = 5
print("수정 후:", lunch_score)

# 토요일 점수 추가
lunch_score.append(4)
print("추가 후:", lunch_score)

# 리스트 길이
print("총 데이터 수:", len(lunch_score))

    실행 결과: 

    월요일 점수: 4
화요일 점수: 5
금요일 점수: 2
월~수 점수: [4, 5, 3]
수정 후: [4, 5, 5, 4, 2]
추가 후: [4, 5, 5, 4, 2, 4]
총 데이터 수: 6

    ⚠️ 주의할 점¶

    1. 인덱스는 0부터 시작해요! scores = [4, 5, 3]에서 첫 번째 값은 scores[1]이 아니라 scores[0]입니다. 범위를 벗어난 인덱스를 쓰면 IndexError가 발생하니 조심하세요.

    2. 슬라이싱의 끝 인덱스는 포함되지 않아요! scores[0:3]은 0, 1, 2번 인덱스만 가져옵니다. 3번은 포함되지 않아요. "끝보다 하나 앞까지"라고 기억하세요.

    ✅ 점검하기¶

    Q1. 다음 리스트에서 "BTS" 를 꺼내려면 어떻게 써야 할까요?

    songs = ["NewJeans", "BTS", "IVE", "aespa"]
    정답 확인 `songs[1]` 인덱스는 0부터 시작하므로 두 번째 값인 "BTS"는 인덱스 1로 접근합니다.

    Q2. 아래 코드의 실행 결과를 예상해보세요.

    fruits = ["사과", "바나나", "포도", "딸기"]
print(fruits[1:3])
    정답 확인 `['바나나', '포도']` 슬라이싱 `[1:3]`은 인덱스 1과 2를 가져옵니다. 3은 포함되지 않아요!

    Q3. 좋아하는 노래 5곡을 리스트로 만들고, 슬라이싱으로 상위 3곡만 출력해보세요.

    예시 정답 확인 
    my_songs = ["Supernova", "Ditto", "After LIKE", "Antifragile", "Hype Boy"]
top3 = my_songs[0:3]
print("TOP 3:", top3)
    출력: `TOP 3: ['Supernova', 'Ditto', 'After LIKE']`
